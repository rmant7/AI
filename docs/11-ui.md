# 11. UI

## Что уже есть

Модуль `app/` — Android-приложение поверх того же `core`: чат через
`Orchestrator`, экран моделей на реальном скорере, настройки эндпоинта. Без
настроек работает встроенный `StubRuntime` — без весов и без сети, но с полным
проходом через роутер, пайплайн, память и Context Engine. Смысл: приложение
должно быть осмысленным сразу после установки, а не показывать ошибку
соединения.

`:app` подключается к сборке только там, где есть Android SDK, поэтому `core` и
`openai` остаются собираемыми и тестируемыми на обычной JVM.

## Разделы

```
Chat        Models        Memory        Knowledge        Pipelines        Settings
```

Чат — вход по умолчанию, но не единственный экран: модели, память, документы и
пайплайны — самостоятельные сущности, и прятать их внутрь настроек чата значит
снова свести продукт к чат-клиенту.

## Chat

```
┌─────────────────────────────────────┐
│ LOCAL AI STUDIO                     │
├─────────────────────────────────────┤
│                                     │
│  User                               │
│  └─ transcript                      │
│                                     │
│  Model                              │
│  └─ response                        │
│                                     │
├─────────────────────────────────────┤
│ 🎤  📷  🎥  📄  +                    │
├─────────────────────────────────────┤
│ Auto ▼        Memory ON   RAG ON    │
└─────────────────────────────────────┘
```

Селектор модели по умолчанию стоит в `Auto`: выбор делает
[Router](07-router.md) + [скорер](03-model-registry.md). Ручной выбор остаётся
доступным — это отладочный инструмент и способ сравнить модели.

Что должно быть видно в ответе, помимо текста:

- какая модель отвечала и на каком runtime;
- что попало в контекст (память, документы, транскрипт) и что **не** попало
  (`AssembledContext.dropped`);
- скорость генерации — она сильно зависит от устройства и нагрева.

```
──────────────────────

```

Группировка по capability, а не по вендору. Для каждой модели показываются
требования и вердикт скорера для этого устройства — включая причину
несовместимости («не хватает 1.2 ГБ RAM»), потому что скрытая модель порождает
вопрос «почему её нет», а видимая с причиной — нет.

Рекомендация никогда не подразумевает удаление установленной модели:
предлагается «оставить обе», см. [03-model-registry.md](03-model-registry.md).

## Pipelines

```
🎤
 │
whisper
 │
memory ───┐
 │        │
rag ──────┤
          ↓
        LLM
          ↓
       memory
```

Граф редактируется визуально, сохраняется в JSON
([08-pipelines.md](08-pipelines.md)), проверяется валидатором до запуска.
Ошибки валидации показываются на узлах, а не текстом в углу экрана: у каждой
проблемы есть конкретный узел или ребро.

## Memory и Knowledge

Память должна быть **читаемой и редактируемой**: список фактов с источником и
кнопкой «забыть». Система, которая выводит о пользователе факты, но не даёт их
посмотреть, воспринимается как неисправная — независимо от качества моделей.

Для документов — статус индексации, число чанков, версия эмбеддера и явная
кнопка переиндексации.
